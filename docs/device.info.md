# Infinix X6851 Device Information

Basic hardware and Android platform information collected from testing on the Infinix Note 40 Pro 5G (X6851).

## Basic Information

| Property         | Value                          |
| ---------------- | ------------------------------ |
| Manufacturer     | Infinix                        |
| Model            | X6851                          |
| SoC              | MediaTek MT6855                |
| Platform         | Dimensity 930 / Dimensity 7020 |
| CPU Architecture | ARM64                          |
| Android Treble   | Supported                      |

## Android Platform

The X6851 supports Project Treble and uses an A/B partition configuration with dynamic partitions.

The device exposes Android partitions such as:

* `boot`
* `init_boot`
* `vendor_boot`
* `dtbo`
* `system`
* `system_ext`
* `product`
* `vendor`
* `odm`
* `super`

## Fingerprint Sensor

The device uses an under-display fingerprint sensor (FOD).

GSI compatibility may vary depending on the vendor implementation and Android build.

## Notes

Partition names, sizes, Android versions, and other software properties may vary between firmware releases.

This documentation records observations from actual X6851 testing and should not be treated as universal for every software version.
